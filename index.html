Data in

No typing. Statements in, sense out.

Import bank statements as CSV, PDF or Excel, or forward bank alert emails, which are checked with DKIM before anything is trusted. Bank linking through RBI's Account Aggregator framework is in testing.

Every transaction is sorted by rules, learned merchant rules and an LLM, and the categorizer learns from each correction. Transfers between a user's own accounts are left out of spending.

The copilot

An AI that looks up your real numbers first.

Ask a money question in plain English. A self-hosted LLM runs a tool-calling loop over a read-only data API, so it answers from your income, spending and goals instead of guessing. The maths is done in code, not by the model.

The tools have no user-ID parameter, and every question carries a short-lived token signed by the core API, so the model can't be talked into reading someone else's data. An eval suite of real questions, graded by code, measures every prompt or model change.

Architecture

Four services, one rule.

Java owns the data, Python owns the thinking. A React 19 web app, a Spring Boot 3.5 core API on Java 21, a separate identity service, and a FastAPI AI service with no database access of its own. PostgreSQL underneath, with 26 Flyway migrations.

When the model needs a user's transactions it has to ask the core API, which decides what that user may see.

Security

Built assuming someone will try.

JWT with refresh-token rotation and reuse detection: a replayed token revokes the whole family. TOTP 2FA with replay protection, Google sign-in, account lockout, and RBAC through a custom Spring Security permission evaluator.

Sensitive fields are encrypted with AES-256-GCM, with an HMAC blind index so encrypted emails can still be looked up. Rate limits per IP and per user, plus a daily AI allowance.

Reliability

Made to keep running.

Resilience4j circuit breakers around the AI: when the model is down, forecasts fall back to a statistical calculation and the app says plainly that AI is offline. Caffeine caching, HikariCP tuning, N+1 fixes and paginated batch jobs.

Over 1,100 automated tests, including Testcontainers on real PostgreSQL. Six GitHub Actions workflows, Grafana monitoring with eight alert rules, and every service containerised on Azure App Service.
